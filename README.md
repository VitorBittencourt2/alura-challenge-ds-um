🚀 Finalizei o Alura Challenge de Data Science! 🚀



Neste desafio, assumi o papel de cientista de dados para a Alura Voz (empresa fictícia) e tive o desafio de ajudar a prever quais clientes têm maior chance de deixar a empresa (Churn Prediction). Foi uma experiência incrível, cheia de aprendizados!



🧐 O que fiz no projeto?



✅ Análise exploratória dos dados (EDA)

✅ Tratamento e limpeza de dados

✅ Engenharia de features e codificação de variáveis

✅ Balanceamento da variável target

✅ Treinamento de modelos de classificação (SVC, Decision Tree e Random Forest)

✅ Avaliação de desempenho usando acurácia, precisão, recall e F1-score

✅ Comparação dos modelos para escolher o mais eficiente



📊 Principais aprendizados:



🔹 A importância da análise exploratória para entender os padrões dos dados

🔹 Como transformar variáveis categóricas para melhorar a performance do modelo

🔹 O impacto do balanceamento da variável alvo nos resultados

🔹 A importância de métricas além da acurácia, como o F1-score, para avaliar melhor os modelos
